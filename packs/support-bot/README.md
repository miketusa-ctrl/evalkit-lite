# Pack: support-bot (Lite)
20 golden cases for customer-support chatbots across fictional shops (Cedar & Pine Outfitters, Nimbus Tickets, Lumen Bakeware Co., Brightloom Streaming). Covers refunds, shipping, password reset, billing, angry customers, out-of-scope, privacy, prompt injection, escalation.
Files: `cases.jsonl` (source of truth), `cases.csv` (spreadsheet). Rubrics: correctness, tone_empathy, policy_adherence, safety_refusal.
